Pointfold

A CLI tool and agent skill for to make it easier to view structured arguments, algorithms, explanations and more in a human-friendly way.

By using the pointfold writing skill, an agent is steered to avoid paragraph-slop, and instead to structure its textual explanations and descriptions in a hierarchical fashion that makes it easier for you to review. Agents produce a bulleted outline that can be viewed as an HTML file that where each bullet point only expands when you click on it. This facilitates reading the content breadth-first instead of depth-first.

Usage

go install github.com/Chriscbr/pointfold@latest
pointfold render notes.md -o notes.html

Requires Go 1.22+. Open the HTML in a browser.

# Should we run a pilot?

- **Case for.** A pilot could test demand. {#pilot}
  - The estimate comes from a small sample. {#sample}
- Weigh the cost against the [uncertainty](#sample).

Documents can include tables, images, and diagrams written using Mermaid (rendered with Pele).
